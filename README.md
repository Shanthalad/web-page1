# RHCSA – Enterprise Cloud Solutions (Assignment)  

This project was developed as part of a **technical assignment assigned by HawkStack Technologies** during a walk-in drive.  
The task was to design a modern, visually rich landing page related to **RHCSA Certification and Enterprise Cloud Solutions** using **HTML and CSS**.

## Assignment Objective
- Create a responsive landing page UI
- Use only HTML and CSS (no JavaScript frameworks)
- Design a modern, enterprise-style layout
- Showcase RHCSA certification and cloud/security concepts
- Focus on UI, layout, and visual presentation

## Implementation Details
- Dark-themed enterprise UI design
- Custom navigation bar with branding
- Hero section with certification messaging
- Gradient text and buttons
- Flexbox-based layout for alignment
- Decorative 3D-style square visuals
- Glassmorphism-style cards
- SVG-based logos and icons
- Responsive design for desktop and mobile screens

## Technologies Used
- HTML5
- CSS3
  - Flexbox
  - Gradients
  - Media Queries
  - Glassmorphism effects
- SVG and image assets
